# Positioning

Startup Landing Lab connects dated startup-website observations to an agent's implementation decisions. Its useful unit is a traceable chain: visitor doubt → observed design decision → transferable principle → original artifact → rendered verification.

It does not train a model, promise conversion gains, or define a single YC aesthetic. YC membership is company metadata, not a quality endorsement.

## Related work reviewed on 2026-10-18

| Project | What it provides | This project's narrower contribution |
| --- | --- | --- |
| [Impeccable](https://github.com/pbakaus/impeccable) | Product context, design vocabulary, shaping, critique and deterministic checks | A dated startup casebook with explicit observation limits and reference-to-artifact decisions |

| [Vercel agent skills](https://github.com/vercel-labs/agent-skills) | Framework and web best-practice guidance | A complementary art-direction and product-storytelling process, not a replacement for engineering practices |

These projects already address originality, product context and verification. We do not claim they lack those capabilities. Our differentiation is the evidence-labelled collection, its decision taxonomy, and three inspectable original demonstrations. The collection is small and predominantly desktop/technical; it must earn broader claims through more research and independent evaluation.

Original instructions and code were authored for this repository. No competitor skill text or proprietary website code was copied. better-web-ui uses its own license; none of its material is redistributed here.
