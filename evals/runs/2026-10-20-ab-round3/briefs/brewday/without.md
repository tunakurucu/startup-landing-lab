# Brief: a landing page in our Next.js app

Grainline is a brew-day log for small craft breweries: readings go in on a brewhouse tablet and the batch record builds itself.
Our marketing site is the Next.js project in this folder, and the homepage is a placeholder.
Build the landing page inside it, using the existing Tailwind setup, colour tokens and Button component.
We deploy a static export, so no API routes or server actions, and I'd rather not add dependencies.
The main action is requesting early access, and there's nowhere to send requests yet.
Head brewers will judge it on a phone with wet hands; the owner who pays reads on a laptop.
We have no brewery customers to name, no time-saved numbers, and we can't claim it handles excise reporting.
Decide on a direction, build and test the page.
