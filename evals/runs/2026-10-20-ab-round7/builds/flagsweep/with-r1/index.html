Flagsweep is an open-source CLI for engineers. It checks each flag in your code against your flag service’s history and lists the ones fully on or off for weeks, with the lines to change.

$pipx install flagsweep

Free and MIT licensed, with no paid plan. Works with LaunchDarkly, Unleash or a plain config file. Read the docs

Listed only when every user has seen the same value for weeks

Flagsweep reads when each flag last changed in LaunchDarkly, Unleash or your config file. A flag makes the list when it serves one value to everyone, on or off, and has stayed that way past your cut-off. Anything still moving stays off the list.

  • recs-model-b is at 50% and moved 6 days ago. It is still an experiment, so it is not listed.

  • free-shipping-banner is on for one segment only. Not everyone sees the same value, so it is not listed.

  • pricing-page-v2 has been at 100% for 19 days. It joins the list once it passes your cut-off.

Each line in the report is one check to take out of your code

The report points at the line; you make the edit in a normal pull request. For a flag that is fully on, keep the code inside the check and delete the check. For a flag that is fully off, delete the check and the code it guards.

Then delete the flag in your flag service, so nothing reads it again.

Rerun the report any day instead of waiting for cleanup day

A flag spreadsheet is only as current as the last person who edited it, and cleanup day keeps moving. Flagsweep answers from your flag service’s history and your code as they are when you run it.

Install with pipx, then point it at LaunchDarkly, Unleash or a config file

$pipx install flagsweep

Free and MIT licensed, with no paid plan. The code is on GitHub; there is no company behind it yet.

Example. Command and option names are illustrative; the docs have the real ones.

$ flagsweep scan . --source launchdarkly
# finds calls like
ldClient.variation('new-checkout-flow', user, false)
$ flagsweep scan . --source unleash
# finds calls like
unleash.isEnabled('new-checkout-flow')
$ flagsweep scan . --source config/flags.yaml
# reads flags defined like
new-checkout-flow: true
