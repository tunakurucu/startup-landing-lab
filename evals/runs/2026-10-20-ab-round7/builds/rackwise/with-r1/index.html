Open the door knowing which rack to pull

You are in gloves, the door is open, and warm air is getting in. Rackwise moves the searching to before the door opens.

  1. Look it up with the door shut

    Search the sample name. The answer is one line: freezer, shelf, rack, box and well.

  2. Pull one rack

    Open the door, pull Rack C from Shelf 3 and count down to Box 4. The door is open for the pull, not for the search.

  3. Log the tube as you take it

    Mark it taken out, or put back. The map changes for everyone, so the next person is not working from last month’s version.

Lab managers see who put each tube where, and when

Every position keeps its history. When a box looks wrong or someone leaves the lab, you read the log instead of asking around.

Does Rackwise monitor freezer temperature?
No. Rackwise is a map of positions: racks, boxes, tubes, who put them there and when. It has no temperature readings and no alarms, so keep the monitoring you rely on now.
