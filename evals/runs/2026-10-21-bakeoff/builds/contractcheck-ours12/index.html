No Postman collection to keep in sync, and no waiting for a client team’s bug report. Three steps, and every pull request gets the check.

    Install the GitHub App

    Add it to the repositories that hold an API and its OpenAPI spec. Public repositories are free.

    Point it at your spec and staging

    Say which file is the spec and where staging answers.

  3. 3

    Open a pull request

    The check runs next to your other checks and fails when a response stops matching the spec.

It reads staging responses. Never production.

Contractcheck runs your spec against the staging API you name, reads the responses and compares them with what the spec promises. Production is never part of the run.

It only sees HTTP responses, so the language and framework behind your API make no difference.

$19 a month per private repo. Public repos are free.

For the team lead approving it: you pay for each private repository the app checks, by the month. Public repositories cost nothing.
