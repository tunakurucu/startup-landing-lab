Find the flags you forgot to delete

Flagsweep is an open-source CLI for engineers who use feature flags. It lists every flag stuck fully on or off for weeks in LaunchDarkly, Unleash or a config file, with the files and lines that still read it.

pipx install flagsweep

Free, MIT licensed, no paid plan.Read the docs

Every listed flag comes with the lines that still read it

The report names each file and line where the flag is checked. Its state tells you which side is dead: a flag stuck on never runs its fallback, a flag stuck off never runs the branch it guards.

A flag is listed when it has served one value for longer than your cutoff

  1. 1

    Find every flag key in the code

    Flagsweep scans the codebase for feature flags and records each place a key is read.

  2. 2

    Read each flag's history

    Each key is checked against the flag service's history: when it last changed, and what it serves now.

  3. 3

    List the flat ones, with their lines

    If a flag has served 100% on or fully off to everyone for longer than the cutoff, it goes on the list with every file and line that reads it.

Read the list before you delete.

A kill switch kept off on purpose also sits still for weeks. In the sample above, search-kill-switch is listed at every cutoff because it has been off since March, and that may be exactly where you want it.

It replaces cleanup day and the flag spreadsheet nobody owns

The list is rebuilt from your code and your flag history each time you run it, so there is nothing to keep up to date by hand.

Install it, point it at your flags, scan one repo

1Install the CLI

pipx install flagsweep

Free, MIT licensed, no paid plan.

2Scan with your flag source: LaunchDarkly, Unleash or a plain config file

# example: read history from LaunchDarkly
export LD_API_TOKEN=…
flagsweep scan . --source launchdarkly --stale-after 30d
