Find out from a failed deploy at 6 pm. Find out in CI, before you deploy.

Driftcheck compares the database schema your migrations will produce with the schema actually running in production. If they differ, it fails the CI job, so the deploy that would break never ships. Open-source CLI for Postgres and MySQL. Free, MIT licensed.

npx driftcheck

Read the docs Read the source on GitHub

One step in your pipeline

Add it before the deploy step. It replaces the schema-check script someone wrote two years ago and nobody has touched since.

  1. Works out the schema your migrations produce

    Every table, column, type, default and index, as it will be after this deploy.

  2. Reads the schema running in production

    Including the column someone added by hand during an incident.

  3. Compares the two

    Each difference is printed with the expected and actual definition side by side.

  4. Fails the job if they differ

    A non-zero exit code stops the pipeline before the deploy step runs.
