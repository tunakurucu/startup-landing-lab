Where a check goes when there is no address

A payee with no last known address on file is reported to your state of incorporation, not to the state where you cut the check. Change the state in the list above and the two unaddressed checks move with it.

What changes the clock

Property type first: payroll checks, customer credits and vendor checks often run on different periods in the same state. Then the last activity date, which a reissue or a written confirmation can reset. Holdfast records both against each item.
