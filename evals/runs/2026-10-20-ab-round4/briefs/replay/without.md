# Brief: replay a failing test on any laptop

Rerun is an open-source command-line tool that records a failing test run in CI and replays it exactly on a developer's laptop: same inputs, same timing, same network responses.
It's for backend engineers who lose afternoons to flaky tests that pass locally.
Install is `npm install -g @rerun/cli`; docs live at https://rerun.example/docs and the code at https://github.example/rerun/rerun.
It's free and MIT-licensed; a hosted team version is planned but not built.
Developers distrust marketing pages; they want to see it work before they believe it.
