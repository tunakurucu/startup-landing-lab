# Fonts

All fonts here are licensed under the SIL Open Font License 1.1; each folder holds its licence text.

| Folder | Source | Changes |
| --- | --- | --- |
| `ibm-plex-mono`, `ibm-plex-sans` | IBM's official WOFF2 files from [github.com/IBM/plex](https://github.com/IBM/plex) | None. These are byte-identical to IBM's files, because IBM Plex carries the Reserved Font Name "Plex" and a modified version could not keep that name. |
| `inter` | [google/fonts](https://github.com/google/fonts) `ofl/inter` | Subset to Latin and the symbols this site uses; weight range limited to 400–700; converted to WOFF2. No Reserved Font Name. |
| `bricolage-grotesque` | google/fonts `ofl/bricolagegrotesque` | Subset; width and optical size fixed; weight range 500–800; WOFF2. No Reserved Font Name. |
| `instrument-serif` | google/fonts `ofl/instrumentserif` | Subset; WOFF2. No Reserved Font Name. |
| `schibsted-grotesk` | google/fonts `ofl/schibstedgrotesk` | Subset; weight range 400–800; WOFF2. No Reserved Font Name. |

The modified files remain under the SIL Open Font License, as it requires.
