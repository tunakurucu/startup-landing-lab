# Casebook: workflow-theater

## Linear · workflow-theater

https://linear.app/ · partial-desktop

Product context occupies the space that generic homepages fill with decoration.

Observed: Large left-aligned sans-serif statement followed by a broad issue-management interface with an agent conversation layered alongside it. Opened Product menu and observed grouped workflow destinations. Escape returned visible keyboard focus to the trigger. App-like hero controls were not functionally verified.

Transfer: Use a recognizable work artifact to make the product concrete. Organize page architecture around the lifecycle of work. Limit visual accents so product state carries emphasis.

Avoid/limit: A rich hero can imply more interactivity than exists. Do not copy controls unless they have useful behavior.

Measured 2026-10-19: desktop h1 64px, weight 510, tracking -0.022em; body 14px; 6 sections; phone h1 38px.
