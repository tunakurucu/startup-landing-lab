# Diagnose repetitive design

| Symptom | Underlying failure | Correction |
| --- | --- | --- |
| Every brief gets centered copy above a browser frame | Product artifact ignored | Compare a split, sequential or spatial entrance using the real artifact |
| Three equal cards say fast, secure, simple | Claims replace explanation | Show one actual workflow and its tradeoffs |
| Palette swap passes as originality | Composition unchanged | Change narrative structure, type roles and artifact grammar |
| Borrowed mascot or lighting effect | Brand recognition mistaken for principle | Transfer organizing function and invent a new treatment |
| Beautiful control does nothing | Visual promise exceeds behavior | Implement a useful local interaction or remove the affordance |
| Product UI is illegible on phone | Desktop shrunk rather than rethought | Show a readable scenario with progressive disclosure |
| Hero stays blank until animation finishes | Loading choreography hides meaning | Render copy/actions immediately with a static visual fallback |
| Mature-company proof pasted into a new brand | Credibility fabricated | Use concrete product explanation and honest scope |

Do not ban components by fashion. A centered hero or card can fit a brief. Require a reason grounded in audience and content; avoid turning anti-pattern advice into a second universal style.
