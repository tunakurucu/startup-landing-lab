# Sherpa

Inspected: 2026-10-19 · desktop-audit · workflow-theater

https://www.withsherpa.ai/

A calm website-management story makes agent work inspectable through sample requests, approvals and ownership.

## Company evidence

YC: verified-yc; batch: P26.

- desktop: 1363 × 936: rendered hero, full-page scan, selected sections and interaction
- tablet: not inspected
- mobile: not inspected

## Observations

### Hero

Centered black sans statement, short ownership-focused explanation and orange Get started action sit on a warm ivory ground. Below, a large browser-like paper sheet has a peelable orange corner; the alternative reveals an agent basecamp illustration.

### Typography

Heavy, compact sans headings with restrained body copy; smaller UI text is reserved for illustrative chat and website previews. Exact families unverified.

### Visual System

Cream and pale beige fields, orange actions and a few green approval controls. Soft bordered cards and fine grid texture frame sample interfaces; wide gutters and alternating centered/split sections keep the long page readable.

### Page Sequence

Hero with peel-back illustration → customer logos → selectable chat request demo → humans/agents capability grid → analytics conversation → illustrative improvement approvals → code ownership → three-step migration → customer accounts → integration grid → FAQ → closing CTA/footer.

### Interaction

Clicked the hero peel control: its accessible description changed to Return to the website preview and the illustration showed an orange agent basecamp. Selected Ship three new pricing plans in the request tabs: selected state and sample preview changed. No approval button or real customer site was operated.

### Accessibility

A skip link, named tabs, checkbox-like switches and FAQ controls were exposed. Example analytics and suggestions identify themselves as illustrative. Keyboard-only, screen-reader and reduced-motion behavior remain untested.

## Interpretation

- Make a service promise tangible with a believable reviewable artifact.
- Separate illustrative examples from verified customer outcomes.
- Answer switching and ownership objections within the main narrative.

Useful when customers fear loss of control over an agent-managed property.

Risk: The interface mockups resemble live integrations; captions must keep sample data unmistakable. Numerous examples add length before a buyer can judge actual implementation.

## Limitations

- One cloud Chromium session at a 1363 × 936 desktop viewport; the site can change after this date.
- Tablet, mobile, keyboard-only, screen-reader, color contrast and reduced-motion behavior were not tested.
- Exact font families, animation timing, implementation details and conversion effects were not independently established.
- Customer quotes and performance statements are company-provided. The illustrative Approve actions were not activated or treated as production approvals.
