## Observations

### Hero

Centered headline, orange emphasis and an operation field with Search/Scrape/Map/Crawl controls; output preview follows immediately.

### Typography

Confident sans-serif display with monospace metadata and code; ordinary body copy explains the operation.

### Visual System

Pale ruled grid, orange actions, small technical markers, code/output surfaces and a saturated orange narrative interruption.

### Page Sequence

Hero/operation preview → customer strip → API/code samples → agent setup → performance claims → capability grid → use cases → library narrative → community → CTA → FAQ/footer.

### Interaction

Clicked Scrape. The action destination changed to a scrape-mode playground URL and the preview displayed structured output. No remote scrape was submitted.

### Accessibility

Semantic structure inspected through browser accessibility output. No contrast, keyboard, screen-reader or reduced-motion audit was completed.

## Interpretation

- Show the shape of input and output before listing features.
- Let technical affordances become a visual motif.
- Interrupt long neutral sections with one purposeful color field.

Choose this approach only if it explains the audience’s actual evaluation task.

Risk: Benchmark claims belong to the company and were not independently validated. Pale microtext and extensive scrolling deserve accessibility checks.

## Limitations

- Single browser, single inspection date; homepage content can change.
- Exact font names, animation timing and implementation libraries were not verified.
- Tablet, mobile and reduced-motion behavior remain unverified.
- Full-page composition and selected interaction states inspected on desktop; this does not imply responsive verification.
