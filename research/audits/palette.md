- tablet: not inspected
- mobile: 390 × 844: computed styles measured 2026-10-19; not visually inspected

## Observations

### Hero

White navigation surrounds a nearly full-viewport dark media canvas. Large white sans type overlays glossy abstract footage near the lower left; purple Book a call and outlined Explore actions sit on the lower right. The short verb in the headline changes with the selected clip.

### Typography

Oversized, heavy sans display for the opening and section headlines; narrow uppercase micro-labels and light body copy establish pace. Exact font families unverified.

### Visual System

White and pale lavender page surfaces, black media frames, violet accents and thin hand-drawn connector marks. Alternating image/text pairs lead through capabilities; purple large-scale graphic fields separate the model and pipeline chapters. Several embedded media panels reported Unable to play media in this browser.

### Page Sequence

Video hero → backer/creator trust row → industry cards → Cut/Flow product demos → Generate/Edit/Storyboard/Characters alternating chapters → example carousel → model accordion → production pipeline → impact controls → API code samples → individual/enterprise tiers → closing video and footer.

### Interaction

Selected the Ink bloom hero clip. The selected checkbox moved from Oil sheen to Ink bloom, the abstract footage changed from an oil surface to purple-blue ink and the headline changed from educates to sells. The action remained on the homepage; no generation was submitted.

### Accessibility

The hero choices, model rows, character samples and API examples expose named controls in the accessibility tree. Some media controls were present with playback failures; no comprehensive accessible-media or keyboard test was done.

## Interpretation

- Let changing examples demonstrate the range of output without changing the core promise.
- Use alternating visual and text chapters to pace a broad creative tool.
- Offer a concrete API example after visual storytelling for technical buyers.

Useful for multimodal creative products with substantial real output to show.

Risk: A rich media-first pitch loses explanatory evidence when clips fail; some text is placed over moving imagery. The long capability inventory can dilute the primary job for a narrow product.

## Limitations

- One cloud Chromium session at a 1363 × 936 desktop viewport; the site can change after this date.
- Tablet, mobile, keyboard-only, screen-reader, color contrast and reduced-motion behavior were not tested.
- Exact font families, animation timing, implementation details and conversion effects were not independently established.
- Embedded video previews in several lower chapters displayed Unable to play media; their intended motion and content were not evaluated. The hero clip switch was observed.
